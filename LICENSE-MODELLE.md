# Mitgelieferte Modelle

Transkribor liefert unter `models/` fremde Modellgewichte mit. Sie stehen unter eigenen
Lizenzen — die MIT-Lizenz dieses Projekts (`LICENSE`) gilt für den Code, nicht für sie.

## pyannote/speaker-diarization-community-1

`models/speaker-diarization-community-1/` — akustische Sprecher-Diarisierung (Stufe 3).

- Urheber: Hervé Bredin und Mitwirkende, pyannote.audio
- Herkunft: https://huggingface.co/pyannote/speaker-diarization-community-1
- Lizenz: **CC BY 4.0** (https://creativecommons.org/licenses/by/4.0/)

Die Lizenz erlaubt Weitergabe und Veränderung, auch kommerziell, und verlangt dafür
Namensnennung — die leistet diese Datei und der Hinweis auf der Einstellungsseite.

Die Gewichte liegen unverändert bei, so wie sie von Hugging Face kommen. Das dortige
Zugangsformular ist eine Kontaktdatenabfrage, keine Lizenzschranke: CC BY 4.0 erlaubt
die Weitergabe ausdrücklich. Sie liegen im Repo, damit Transkribor ohne Hugging-Face-Konto,
Token und Häkchen im Browser läuft.
